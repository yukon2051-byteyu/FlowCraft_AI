- 進め方：**1タスクずつ実装 → テスト → 説明 → 確認をもらってから次へ**

## 判断基準

すべての設計判断は、次の問いで評価する。AI機能の数や画面の華やかさでは判断しない。

1. 一度きりの作業でも、毎月の作業でも、安定して実行できるか
2. **処理が終わったことと、業務が正しく完了したことを区別して示せるか**（完了基準）
3. 入力データの変化に気づけるか
4. 誤集計のリスクを検出できるか
5. 問題が起きた理由を利用者に説明できるか（判定の根拠）
6. 担当者が変わっても業務を継続できるか
7. 作成した作業手順と完了基準を安全に管理できるか
8. **自動化の前に、作業をなくす・減らす・そろえる余地を確かめられるか**（カイゼン支援。ただし利用者に強制しない）
9. **無人で実行する前に、接続・処理・品質の確認を通ったことを示せるか。設定を変えたら確認をやり直させられるか**（無人定期実行）
