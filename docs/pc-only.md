# PC専用化の方針（2026-11-14：スマートフォン対応の廃止・PC専用化指示書）

FlowCraft AI は **PC専用の Web アプリ**として開発する。スマートフォン・タブレット向けの専用UIや操作対応は作らない。
その分の工数を、PC画面の操作性・業務の流れの分かりやすさ・処理機能・品質検証・実行履歴・業務改善診断に使う。

## 1. 対象

| 対象 | 内容 |
|---|---|
| OS・ブラウザ | Windows 11 の Google Chrome・Microsoft Edge |
| 操作 | マウス・キーボード |
| 主要な確認解像度 | **1920×1080**（デスクトップ）・**1366×768**（ノートPC） |
| 対象外 | スマートフォン（iPhone・Android）、タブレット、タッチ操作専用の機能、モバイル向けナビゲーション |

## 2. スマートフォンから開いたとき

アプリ本体の代わりに、次の案内だけを出す（`src/pages/PcOnlyNotice.tsx`。どのURLでも同じ）。

> **FlowCraft AIはPC専用です**
> FlowCraft AIは、Excel業務の作成・編集・実行を行うため、PCでの利用を推奨しています。Windows PCのChromeまたはEdgeからアクセスしてください。

- 判定はブラウザの識別文字列（User-Agent）で行う（`src/device.ts`）。**画面幅では判定しない**（PCで狭くしたウィンドウを誤って止めないため）
- タブレットは対象外だが、案内も出さない（指示書 §5 はスマートフォンが対象）

## 3. 画面幅の指定（Tailwind のブレークポイント）の使い分け

| 指定 | 幅 | 扱い |
|---|---|---|
| `sm:`（640px）・`md:`（768px） | スマートフォン・タブレットとの切り替え | **使わない**。2026-11-14 に、PCで効いていた値へ一本化した |
| `lg:`（1024px）・`xl:`（1280px）・`min-[1340px]:` など | PCのウィンドウ幅に応じた調整 | **使ってよい**（カード配置・表の幅・余白など） |

1366px と 1920px ではどちらも `lg:`・`xl:` が効く。1366px で窮屈になる配置は、`xl:` 以下の値で調整する。

## 4. 今後の開発ルール

1. PC向けの UI/UX を最優先する
2. スマートフォン対応を実装要件に含めない
3. モバイル向けのコンポーネントを新しく作らない（`sm:`・`md:` の指定も使わない）
4. PCでの操作性を優先して画面を設計する
5. 表示の確認は **1920×1080 と 1366×768** で行う（`e2e/pc-only.spec.ts`、`scripts/screenshots.mjs`）
6. スマートフォン向けの表示テストは行わない（PC専用の案内が出ることだけを確かめる）

## 5. 2026-11-14 の整理の記録

### 削除したもの
| 対象 | 内容 |
|---|---|
| `HeroVisualCompact`（`src/components/top/HeroVisual.tsx`） | TOPのヒーロー図のスマートフォン用の簡易版（4段階の帯） |
| TOP のスマートフォン用の表示切り替え | `sm:hidden`（簡易版の図）・`hidden sm:flex`（PC用の図） |
| ヘッダーの短いボタン名 | スマートフォンだけで出していた「試してみる」（PCは「自分のExcelで試す」のまま） |
| ワークスペースの幅による案内（`WorkspacePage` の旧 `PcOnlyNotice`） | 幅1024px未満でアプリを隠して出していた案内。アプリ全体のPC専用の案内に置き換え |
| `sm:`・`md:` の指定 46か所（13ファイル） | スマートフォン・タブレット向けの値を消し、PCで効いていた値だけを残した（PCの見た目は変わらない） |
| 画面幅チェックのタブレット（768px）・スマートフォン（390px） | `scripts/screenshots.mjs` を 1920×1080・1366×768 に変更 |

### 残したもの（PC向けの調整）
- `lg:`・`xl:` の指定（58か所）：PCのウィンドウ幅に応じたカード配置・余白・文字の大きさ
- TOPのヒーロー図の `useWideHero`（1340px以上で図の一部を右へずらす）：PCの画面幅に応じた調整
- `prefers-reduced-motion`（動きを減らす設定）への対応：アクセシビリティのため。スマートフォン用ではない
- `HelpTip` の `window.innerWidth`：説明の吹き出しを画面の端で切らさないための位置計算（PCでも使う）

### 残っているモバイル関連のコード
- `index.html` の `<meta name="viewport">`：スマートフォンで PC専用の案内を読める大きさで表示するために残す
- `src/device.ts`（スマートフォンの判定）と `src/pages/PcOnlyNotice.tsx`（案内）：指示書 §5 の案内のために必要

タッチ操作専用のイベント処理・モバイル用のナビゲーション（ハンバーガーメニュー）・モバイル専用の状態管理は、もともとなかった。
不要になった依存関係はない（削除した部品はアイコン〈lucide-react〉など、ほかでも使う部品だけを使っていた）。
